# EduSync — демонстрационный сайт

## Запуск
Откройте `index.html` в браузере. Рекомендуется запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000

## Страницы
- `index.html` — публичный motion-design лендинг.
- `login.html` — вход в демо-аккаунт.
- `register.html` — создание демо-аккаунта.
- `dashboard.html` — демонстрационная панель администратора.

## Возможности панели
- Создание аккаунта и вход (демо-авторизация через localStorage).
- Загрузка файлов XLSX, XLS, CSV через категории или drag-and-drop.
- Список загруженных файлов, удаление и отображение размеров.
- Анимированная демонстрационная проверка данных.
- Статичный пример расписания.

## Важные ограничения
Это frontend-прототип. Реальной серверной авторизации, безопасного хранения паролей, отправки файлов на сервер, проверки структуры таблиц и генерации расписания нет. Сведения об аккаунте и список метаданных выбранных файлов хранятся только в localStorage текущего браузера. Само содержимое файлов не загружается и не сохраняется. Не используйте реальные пароли.
